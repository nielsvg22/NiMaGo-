# NiMaGo-logoassets

Het enige losse beeldmerk is de zalmroze **N-ribbon**. Geen extra zwarte N naast het woordmerk. Het woordmerk bestaat uit het roze N-symbool gevolgd door de donkere letters “iMaGo”.

SVG = schaalbaar en bewerkbaar. PNG = transparante exports, behalve de app-iconvarianten met een vaste achtergrond. Gebruik `01_logo_primair.svg` op lichte ondergronden, `03_logo_donker.svg` op donkere ondergronden en `08_beeldmerk.svg` voor favicon. Voor definitief gebruik: controleer merkrechten en drukproef.
